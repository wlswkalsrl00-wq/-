# 미니 마리오 스타일 플랫폼 게임

브라우저에서 실행 가능한 간단한 마리오 스타일 2D 플랫폼 게임입니다.

## 실행

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` 접속.

## 조작

- `←` `→`: 이동
- `Space` / `↑`: 점프
- 적을 위에서 밟으면 처치
- 깃발에 닿으면 클리어

## 구성

- `index.html`: 게임 레이아웃
- `style.css`: UI 스타일
- `game.js`: 물리, 충돌, 렌더링, 게임 로직
